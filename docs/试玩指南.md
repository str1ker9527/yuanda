# 原搭 0.2.0-preview.10 开发预览版试玩指南

本文注明「仓库」的路径相对源码根目录，注明「便携版」的路径相对 `原搭.exe` 所在文件夹；不要把相对路径当成本机固定地址。Mac 使用者先看 [Mac 开发与迁移指南](MAC_DEVELOPMENT.md)。本版验证范围以[发布记录](RELEASE_NOTES.md)为准，以下是使用步骤，不是要求你手动完成验收。

你不需要先学编程。先用示例体验，再回到主窗口修改。**主窗口负责编辑；预览窗口和浏览器负责体验交互。**

页面文件夹操作见第 18 节；工作区操作见第 17 节：左上菜单、右键、拖入预览、参考线及面板停靠。MCP 直接控制和基础 RP 导出见第 8–9 节。样式功能看第 16 节，图片功能看第 15 节；需要导入自己的图片时，使用顶部的图片入口。

## 1. 打开新版和示例

**窗口：Windows「文件资源管理器」。**

以下步骤以 Windows 为例。先从源码构建，或取得完整便携目录。在资源管理器进入你的仓库目录，再进入：

```text
dist\原搭-0.2.0-preview.10
```

双击 `原搭.exe`。应看到左上方新建、打开、保存图标，下方「文件」「编辑」「视图」等菜单，右上方「预览」「导出」、中间画布和周围的编辑面板。便携版自带运行环境；不要只移动 exe，要保留整个文件夹。旧版本是独立目录，不会自动迁移其中的工程。

**窗口：原搭主窗口 → Windows 打开文件窗口。**

新版便携版首次打开显示两页“图片与跳转演示”，可以直接尝试 RP 导出。下面第2–7节使用功能更丰富的三页演示；先保存自己的内容，再点击「打开」，在打开文件窗口从仓库根目录找到：

```text
samples\yuanda\原搭体验-0.2.yuanda
```

点「打开」。页面列表应包含「产品预约」「体验工作台」「交互实验室」。这份样本可以继续编辑；想保留原样，可先按 `Ctrl + Shift + S` 另存为自己的项目。

## 2. 走一遍预约流程

**窗口：原搭主窗口 → 新出现的「原搭 · 交互预览」窗口。**

1. 在主窗口点击「预览」。
2. 在预览里点击「预约体验」，应出现弹窗。
3. 输入称呼，点击「确认预约」。提示先显示正在确认，约一秒后显示「预约成功」。这只是本地演示，不会向外提交预约。
4. 点击「关闭」，再点「查看工作台」，进入第二页。
5. 点击「打开交互实验室」，进入第三页。

在编辑器里点击按钮是选择元件。要测试按钮实际做什么，请在预览窗口操作。

## 3. 体验状态、表单、条件和数据列表

**窗口：交互预览窗口，第三页「交互实验室」。**

| 点哪里、怎么操作 | 应该看到什么 |
| --- | --- |
| 点「显示详情」，再点「显示概览」 | 左上内容区域在两种内容间切换，这就是动态面板的两个状态。 |
| 右上直接点「确认填写」 | 显示填写和勾选提示。输入称呼、选择用途、勾选确认选项后再点一次，会显示你的称呼与用途。 |
| 向下滚动，在计数区点击增加按钮，再点「检查是否达到 3 次」 | 少于 3 次时提示还差几次；达到 3 次后给出通过提示。重置按钮把计数归零。 |
| 点「按优先级排序」 | 任务列表按数字从小到大排列。 |
| 点「只看优先级 2 以上」，再点「显示全部」 | 先只显示优先级大于或等于 2 的任务，再恢复所有任务。 |
| 在列表上方输入一件要做的事，点旁边的添加按钮 | 新任务出现在列表中，优先级为 4；内容较多时可在列表内滚动。 |
| 点预览顶部「重新体验」 | 恢复示例的初始变量、输入和列表。 |

这里的操作只影响当前演示过程，不会把填写结果写回设计项目。回到编辑器修改后，需要重新打开预览，查看新设计。

## 4. 改文字、外观和位置

**窗口：原搭主窗口。**

1. 双击一段普通文字，或选中后按 `Enter`，输入自己的内容，按 `Ctrl + Enter` 完成。
2. 选中按钮或矩形，在「样式」面板修改文字、颜色、圆角、位置或尺寸。
3. 拖动元件移动；拖动选框手柄改变大小，按住 `Shift` 缩放可保持比例。按住 `Shift` 点击可以多选，再进行对齐或组合。
4. 从「元件库」把元件拖到画布，或双击元件库条目添加。输入框、多行文本框、勾选项、下拉列表和表格都可以继续设置内容。
5. 输入框可以选择文本、密码、数字、邮箱、日期、电话、网址或搜索类型；输入框与多行文本框还可设只读、禁用和最大输入长度。数字和日期不使用字符长度限制。请在预览里测试输入效果。
6. 按 `Ctrl + C`，再按 `Ctrl + V` 粘贴复制时的内容；即使随后修改或删除原件，普通副本仍取自复制时的快照。母版副本继续跟随仍存在的母版定义。

按 `Ctrl + Z` 撤销，`Ctrl + Shift + Z` 重做。顶部「吸附」是网格、参考线和元件吸附的总开关；各项可在「视图 → 吸附」分别设置。按住 `Ctrl` 滚轮缩放，点击缩放百分比适应窗口。

你正在输入时，Agent 修改别处不会清掉这段草稿。如果同一段文字也被 Agent 修改，完成编辑时会保留草稿并提示选择：「用我的输入替换」「保留为新文字」或「采用最新内容」。先读清两份内容再选择。保存或关闭前，软件会先等待正在编辑的内容提交；遇到冲突时先处理提示，再保存或关闭。

## 5. 把工作区摆顺手

**窗口：原搭主窗口。**

- 拖动「页面」「概览」「元件库」「母版」「样式」「交互」「注释」面板的标题栏，可调整位置、停靠或浮动；从顶部「面板」入口找回隐藏的面板或恢复布局。
- 页面和母版可以在画布上方以标签打开；点击「画廊」查看缩略图，再点击要编辑的页面或母版。
- 在页面列表拖动页面可调整顺序或层级；这些修改会进入撤销记录。关闭标签不会删除页面。
- 显示标尺和参考线后，从标尺拖入一条参考线；拖动可调整，双击可精确填写位置，选中后按 Delete 删除，也可拖回标尺删除。网格显示与吸附可以分别开关。
- 选中一个元件后在「注释」面板写说明；取消选择后可写页面说明。

## 6. 试一次共享样式和母版

**窗口：原搭主窗口。**

共享样式用来统一外观：选中一个普通按钮，在「样式 → 共享样式」点击「新建」，输入名称。再选中另一个普通按钮，从共享样式下拉框选它。点击「管理」修改这份共享样式，两处一起更新。直接修改某个元件的外观会留下局部覆盖，仍保留样式关联；未覆盖的属性继续跟随共享样式，可在样式工具中清除覆盖。

母版用来复用一组内容：

1. 在普通页面选中两个或更多元件，打开「母版」面板，点「从所选元件创建母版」，填写名称。
2. 在母版列表点「插入」，得到另一个实例；点「在画布编辑」，打开母版专用画布。
3. 在母版画布修改文字或位置，再点普通页面标签返回，应看到相关实例同步更新。
4. 在普通页面从「概览」选择实例中的一个文字元件，在样式面板修改「当前实例文字」。只有这个实例的文字改变，其他布局仍跟随母版。
5. 图片实例可以点击「替换当前实例图片…」；点击「恢复母版内容」可清掉当前文字/图片覆盖。
6. 需要完全独立编辑时，点击「解除当前实例关联」或母版面板中的「解除母版关联」。外观保留，之后不再同步。

母版画布可插入另一个母版形成嵌套，循环引用会被拒绝。实例文字和图片可以单独覆盖；母版还可建立自己的视图，在不同尺寸下使用不同布局，入口见第 14 节。母版没有页面级事件，元件自己的交互仍可编辑。

## 7. 制作一个点击后会反馈的按钮

**窗口：原搭主窗口。**

1. 添加并选中一个普通按钮，在「交互」面板选择点击事件。
2. 点「添加条件分支」，保留默认的独立判断，不填写条件。
3. 点「添加动作」，选择修改文字，作用于这个按钮自己，内容填「已收到」。保存动作设置。
4. 点「预览」，在预览里点击按钮，应出现新文字。

同一分支可追加等待、显隐、跳页、修改变量或面板状态等动作，按列表顺序执行。分支和动作都可复制、上移或下移。要学习复杂配置，可回到三页样本，选中实验室里的按钮，在「交互」面板查看它如何读输入、判断条件和修改列表。

在样式面板还能找到「转为动态面板」「转为数据列表」「项目变量…」；画布上方的「管理视图」配置自适应布局。切换视图后，普通拖动和属性会按「修改当前视图／修改全部视图」保存；文字和交互共享，具体见第 14 节。矢量路径和连接线可从元件库添加，再用对应编辑工具调整。

## 8. 让 Agent 直接改画布

**窗口：原搭主窗口。**

点击「Agent 工作台」，点「试试：添加卡片」或「试试：换个配色」，再点「检查指令」。检查通过后点击「应用修改」，画布会改变；`Ctrl + Z` 可撤销整批修改。如果检查后项目发生变化，需要重新检查。

以上是可选的手动批量入口。新版通过 MCP 让 Agent 直接操作，不需要粘贴指令。保持原搭打开，在已接入的 **Codex 聊天窗口**直接说明要改哪里，Agent 会调用工具更新画布、选中目标、保存和导出。「复制 Agent 接入说明」提供其他客户端的本地配置。详见 [Agent 接入](Agent接入.md)。

## 9. 保存项目和导出网页

**窗口：原搭主窗口 → Windows 保存文件窗口。**

点击「保存」，选择自己的文件名，例如 `我的第一个原型.yuanda`。以后用原搭「打开」继续编辑。另存一份用 `Ctrl + Shift + S` 或「导出 → 原搭工程备份」。新版便携版默认保存到自身的 `projects` 目录。覆盖已有文件时，旁边的 `.bak` 是上一份备份；恢复记录不能替代主动保存。

**窗口：原搭主窗口 → 保存文件窗口 → 浏览器。**

点击「导出 → 可交互 HTML」，保存为 `我的原型.html`，再从资源管理器双击打开。它包含项目图片和交互运行器，可以离线演示。要继续设计，打开 `.yuanda`；HTML 里的演示状态不会自动保存回项目。

新版原创样本位于 `samples/yuanda/原搭体验-0.2.yuanda`，对应网页位于 `exports/原搭体验-0.2.html`。旧版样本保留。

**基础 RP 导出已启用。**选择「导出 → Axure 项目 .rp」即可保存受支持的矩形、文字、按钮、多页、静态 PNG 和无条件单击跳页。初次可打开便携目录 `projects/原搭-图片与跳转演示.yuanda`。页面文件夹（包括空文件夹）、复杂控件、变量、母版或高级样式会列出原因并停止导出，原工程不变。基础样本已通过 Axure 编辑/保存/预览/重开；新独立写出的图片和跳转目前完成自动解码验证。原搭暂不导入任意 RP，继续编辑请保存工程备份。

## 10. 试玩新增的分页和行标记

**窗口：原搭主窗口 → 打开文件窗口。**先保存自己的项目，再点击「打开」，从仓库根目录按以下相对路径找到文件：

```text
samples\yuanda\层级与分页体验.yuanda
```

**窗口：新打开的交互预览窗口。**

1. 点主窗口的「预览」。在第一张卡片的输入框写一句备注，勾选「标记此行」。
2. 点「下一页」，再点「上一页」。备注和勾选状态应还在。
3. 点「只看优先项」，只显示优先级较高的任务；「显示全部」恢复列表。
4. 点「删除标记行」，会删除这次预览中被标记的行。关闭再重新预览，恢复设计时的数据；这些演示操作不会改掉你的项目文件。

**窗口：原搭主窗口。**从「概览」选中「任务列表 · 每页 3 条」，在「样式」面板里修改「每页数量」或「初始页」。保存后再预览，会采用新设置。留空每页数量表示显示全部。

## 11. 试一次层级和数据导入

**窗口：原搭主窗口 → 概览面板。**

展开「页面抬头（含嵌套组）」和里面的「标题与说明」。点一个组可选中整组；双击普通组进入组内编辑，点「退出组」返回。选中普通组后点「缩放组」，可一起调整位置和大小。树节点拖到组、面板状态或行模板中可改变归属，拖到同级边缘可调整前后顺序；不合适的归属会给出提示。可按 `Ctrl + Z` 撤销。

**窗口：原搭主窗口 → 样式面板 → 导入数据窗口。**

1. 在概览选中「任务列表 · 每页 3 条」，点「导入 CSV / Tab…」。
2. 选择项目里的 `samples\yuanda\任务导入示例.csv`。保持 CSV、首行为表头、追加模式。
3. 点「预览导入」，检查标题、说明、优先级分别对应正确的列。预览不会改项目。
4. 点「确认追加数据」。两条新数据会加入列表；`Ctrl + Z` 可以一次撤销这次导入。替换模式的按钮会显示「确认替换全部数据」。

当前支持 UTF-8 的 CSV 或 Tab 分隔文字，不直接读 Excel 的 `.xlsx`。选「替换」会替换整张数据表、清空标记并回到第一页，导入窗口会提前说明。数字列遇到“不是数字”的内容会拒绝导入，方便先改对再继续。

## 12. 把自己的设计存成可重复使用的元件库

**窗口：原搭主窗口 → 左下「元件库」面板 →「本地库」。**点击「加载 .yuandalib」，在打开文件窗口选择：

```text
samples\libraries\交互卡片.yuandalib
```

在「浏览文件夹」里选「交互卡片」文件夹，点条目下的「插入」。回到主窗口点「预览」，卡片里的按钮和状态仍可操作。每次插入是独立副本，`Ctrl + Z` 可撤销整次插入。

**窗口：原搭主窗口。**按住 Shift 选中自己想复用的几个元件，点「本地库 → 新建库」，填写名字并保存，再点「保存选区到库」。可填写条目名称、说明和所在文件夹。库中的「导出库」会生成 `.yuandalib`；以后在另一项目「加载 .yuandalib」即可复用。无需复制代码。

库文件是原搭自己的格式，不是 Axure 的 `.rplib`。加载时保留一份托管副本，后续改库不会自动改写原文件，也不会改动已插入项目的副本。「定位库文件」打开托管文件所在目录；「移除库」不删除最初加载的文件。条目仅保存基础视图；外部页面跳转或选区外引用被清理时会显示「保存说明」。

## 13. 试试可以滚动、拖动和固定的面板

**窗口：原搭主窗口 → 打开文件窗口。**粘贴下面路径，打开后再点「预览」：

```text
samples\yuanda\面板交互体验.yuanda
```

**窗口：新打开的预览窗口。**拖动卡片的空白区域、滚动列表、切换内容，观察右下角提示如何保持位置。输入框和按钮优先接收输入，拖它们不会把整块面板带走。

**窗口：原搭主窗口 → 概览 → 选中动态面板 → 样式。**

1. 点「复制当前状态」，会复制该状态和内部内容；可上移、下移或拖动状态列表，`Ctrl + Z` 撤销。排序不会偷偷改变预览初始状态，要改初态请点「设为预览初始状态」。
2. 点「尺寸、滚动、固定与拖动…」，选择尺寸模式、横纵滚动、固定对齐与边距，以及是否允许访客拖动。
3. 点「应用面板设置」，再预览。固定位置以预览工具条下方的可用区域计算；「随当前状态内容扩大或缩小」在预览中计算，手动改宽高会回到固定尺寸。

这些交互也会带入导出的 HTML；预览中的拖动和输入不修改设计文件。

## 14. 同一份内容，编辑桌面、平板和手机布局

**窗口：原搭主窗口 → 打开文件窗口。**粘贴下面路径，然后点「预览」：

```text
samples\yuanda\自适应与母版体验.yuanda
```

**窗口：新打开的预览窗口。**在卡片里输入一句话，点击两次「点击 +1」，再点「手机」「平板」「桌面」。布局变了，输入和计数应该还在。顶部选「自动适应」后，拖动窗口边缘调整宽度，也会自动切换。

**窗口：原搭主窗口，画布上方。**选择「手机」视图，范围保留「修改当前视图」。选中标题后拖动或修改颜色，再切回「基础视图」：基础排版不会跟着改变。选「修改全部视图」后改颜色，各视图会一起更新。文字、图片、交互与结构设置共享，界面上方会提示当前范围。

**窗口：原搭主窗口 → 样式面板。**先把画布上方切回「手机」和「修改当前视图」，再选中元件按 Delete：这时只取消放置，并保留内容。在概览中选中标为未放置的元件，点「置入此视图」可以恢复。要彻底删除，才选「修改全部视图」再删除。选中有独立覆盖的元件，可以点「恢复全部继承」或只恢复某个属性；撤销仍用 `Ctrl + Z`。

**窗口：原搭主窗口 → 管理视图。**可查看继承关系、编辑尺寸，或者把独立页面视图建为共享集，供其他页面引用。共享集的名称、尺寸、断点与继承会一起更新，但各页面的元件位置分别保存。旧独立视图要建立继承链，先转成共享集。修改共享集前留意窗口里的说明。

**窗口：原搭主窗口 → 母版面板。**找到「响应式交互卡片」，点「在画布编辑」修改主定义，画布上方也可选择组件视图。

**窗口：原搭主窗口 → 普通页面 → 样式面板。**返回页面，选中卡片实例，在右侧「母版实例视图」下拉框选择「自动匹配完整视图名称路径」，就会随页面的同名继承链切换；也可以固定使用某个母版视图。实例在当前视图移动或取消放置后，母版后续新增内容仍属于同一个实例。

取消放置像是“这一尺寸的排版不用它”，临时隐藏则是“仍在这张排版里，先不显示”。预览中的显示动作不能强行显示没有放置的元件。

## 15. 图片导入、裁剪与导出

**窗口：原搭主窗口 →「打开」文件窗口。**打开项目内 `samples/yuanda/图片编辑体验.yuanda`，先另存为自己的文件。图片都由原搭示例生成，不需要下载外部素材。点击「预览」，可以试动图计数、拉高图片卡片和更换图片上的文字。

**窗口：原搭主窗口。**回到编辑器，单击一张图片，在「样式」面板向下找到图片设置。

| 你想做什么 | 点哪里、会发生什么 |
| --- | --- |
| 放进自己的图片 | 顶部图片入口选择文件，或从资源管理器拖入画布。支持 PNG/JPEG/WebP/GIF；BMP 和受支持的静态 SVG 会提示转换为 PNG。一次最多 8 张，文件选择入口一次 1 张。 |
| 粘贴截图 | 在别的应用复制图片后，点原搭画布按 Ctrl+V。正在文本框里打字时，Ctrl+V仍用于文字。部分应用的剪贴板格式可能不同；真实系统剪贴板仍需在你的使用环境验收。 |
| 裁剪一部分 | 点「裁剪 / 选区…」，在大图上拖选框，或填写区域数值，再点「应用裁剪」。画布外框不变；想按实际像素大小显示，再点「原图尺寸」。取消不会修改项目。 |
| 翻转、调色 | 勾选「水平翻转」「垂直翻转」；展开「调色」，调色相、饱和度、亮度、对比度。原图保留，Ctrl+Z可撤销。 |
| 拉伸时保住边角 | 点「保持角部…」，拖动四条线或输入边缘宽度。四角保留，中间区域拉伸；过小外框会一起缩小角部，避免倒置。 |
| 在图片上写字 | 展开「图片上的文字」，填写内容并勾选「显示叠加文字」。文字不跟随图片翻转或调色。 |
| 分成独立图片 | 点「切片…」，选左右、上下或四片，调切点并应用。切片前关闭角部与叠字，去除全部视图和交互状态的边框、圆角、复杂填充、阴影与模糊；界面提供明确提示。一次撤销恢复整张图。 |
| 复制或剪切一个区域 | 在「裁剪 / 选区…」切换到「复制 / 剪切选区」。复制生成 PNG；剪切还会把原图片该区域显示为透明，仍可撤销。 |
| 缩小显示资源 | 点「优化副本…」选择宽度/格式，生成副本。原图仍保存，动图优化后静止；「恢复使用原图」恢复动画与原始清晰度。此功能不保证项目文件更小，因为原图和副本都保留。 |
| 更换或清空 | 「替换图片…」换素材；「清除图片」保留元件的框、文字及交互。开启自动适应时，更换会按原图尺寸调整外框。 |

图片内容、裁剪和调色在所有视图共享；位置和框尺寸遵循上方「当前/全部」范围。母版实例可单独替换图片和文字，其他图片设置要打开母版画布或先解除关联。图片编辑窗口打开期间，如果 Agent 修改了同一张图，窗口会保留你的选区并提示冲突，避免覆盖更新。

**窗口：原搭主窗口 → 保存/导出文件窗口。**点「保存」得到可继续编辑的 `.yuanda`；点「导出」得到 `.html`。再在文件资源管理器双击 HTML，用浏览器体验。图片和交互代码都包含在 HTML 里，不需要把图片文件夹一起发出去。项目总图片量当前限制为 24 MiB，切片、实例和优化副本都计入；超过时会拒绝该次修改，不截断图片。

这个版本统一了以前编辑器和网页不一致的默认留白；打开旧项目时请预览复查文字位置。命名样式继承和格式刷现已实现；`.rp` 只支持文档列明的基础范围；面板内部仍按矩形区域滚动和裁剪，设置外框圆角不会自动改变子内容的裁剪形状。

## 18. 用文件夹整理页面

**窗口：原搭主窗口 → 打开文件窗口。**先保存自己的项目，再点左上「打开」。使用便携版时，在 `原搭.exe` 所在文件夹中找到：

```text
projects/页面目录体验.yuanda
```

从源码运行时，在仓库中打开 `samples/yuanda/页面目录体验.yuanda`。预期左侧有「产品设计」「订单流程」「待整理」三个文件夹，以及「产品首页」「订单详情」「完成页」「使用说明」四个真实页面。点一下文件夹只会选中目录；当前画布和已有标签保留，不会打开空白页。

**窗口：原搭主窗口，左侧「页面」面板。**

| 想做什么 | 怎么操作 | 预期结果 |
| --- | --- | --- |
| 新建目录 | 点页面标题栏的文件夹图标，或「项目 → 添加文件夹」，填写名称后确定 | 若当前选中文件夹，新目录建在它里面；选中普通页面时，建在该页面同级。 |
| 新建子页面或子目录 | 在文件夹或页面行上右键，选「添加子页面」或「添加子文件夹」 | 页面直接创建；目录先填写名称。页面仍可拥有子页面或子目录。 |
| 改名 | 右键选「重命名…」，也可选中树行后按 F2 | 名称更新，页面 ID 保持，所以已有跳转不因改名失效。 |
| 展开或收起 | 点击行名前的小箭头；目录也可双击，或选中后按左右方向键 | 只隐藏/显示树中的后代；文件夹状态随工程保存，不影响预览里的页面。 |
| 拖动归类 | 把页面或目录拖到目标行中间；要排序则移到目标行上边或下边，看到标记再松手 | 中间表示放进目标；上下边表示成为同级并排序。不能放进自己或自己的后代。 |
| 用键盘移动 | 选中树行，按 Ctrl+上/下调整同级顺序，Ctrl+右缩进到前一兄弟，Ctrl+左退出一级；Alt+方向键同样可用 | 页和目录共用排序规则，可撤销。Mac 实现使用 Cmd，对应真机操作仍待验证。 |
| 用下拉框调整 | 先选中树行，在页面面板底部查看「页面/文件夹 · 名称」，选择「上级页面或文件夹」 | 下拉框显示当前真实父项，排除自身和后代；旁边上/下移只改变同父级的混合顺序。 |
| 删除整个目录 | 右键选「删除整个文件夹…」或按 Delete，先读影响数量，再取消或确认 | 确认会删除全部子页面、子目录和其中的元件；Ctrl+Z 一次恢复整批。不能删光项目所有真实页面。 |

删除普通页面时，它的子页面和子文件夹会保留并提升一级；这与删除整个文件夹不同。Agent 同时改动时，旧拖动或菜单会取消；已打开的命名/删除确认若版本过期，会拒绝写入，请关闭后按最新内容重试。

**窗口：原搭「预览」窗口。**点击预览后应从树中的第一个真实页面「产品首页」开始；点「查看订单 → 完成订单 → 返回首页」体验跨目录跳转。文件夹不会变成预览页，收起目录也不会隐藏导出内容。画廊仍显示真实页面和母版。

**窗口：原搭保存窗口或文件资源管理器。**保存 `.yuanda` 后关闭再打开，目录名称、父级、混合顺序与文件夹折叠状态应保留。便携版附带的独立演示在 `exports/页面目录体验.html`；从源码取得的演示同样在仓库 `exports/页面目录体验.html`。含目录的工程目前不能导出 RP；不要为了导出而删除唯一工程中的目录或内容。
