# 安全与隐私说明

原搭是开发预览项目。目前没有长期支持分支、独立安全审计或已承诺的修复时限。报告问题时请注明应用版本和操作系统；修复及验证范围会随具体版本说明发布。

## 报告安全问题

若仓库的 **Security → Report a vulnerability** 提供私密报告入口，优先在那里报告。若未显示该入口，可开一个不含漏洞细节的 Issue 请求私下联系；不要先公开可利用步骤、有效令牌、个人工程或敏感日志。本项目未设置专门安全邮箱，不应把猜测的地址当成报告渠道。

私密报告中可以提供受影响版本、复现前提、最小自有样本和观察到的影响。对文件读写或本地接口问题，尽量用临时文件与空白工程复现。

## 本地 Agent 的权限边界

Agent 通过标准 MCP 调用本机 HTTP 接口。服务监听 `127.0.0.1` 的随机端口，校验 Host、临时 Bearer 令牌并拒绝带网页 Origin 的请求；连接进程只使用固定接口，不提供任意命令执行或通用文件读写工具。

这些控制减少网页误连和未持有令牌的请求，**不构成同一电脑上恶意进程的隔离边界**。有权限读取连接文件的程序可能获得当前项目的 Agent 访问能力。不要同步、提交或分享连接文件，不要将该端口转发到网络。

Agent 能直接修改当前打开的工程，保存和导出会写入文件。写入必须携带版本号，整批模型修改可撤销；撤销不是已导出文件的删除或系统级回滚。应只给可信 Agent 配置连接，并在发送工程内容给外部模型前确认其数据处理方式。

实现入口：[`agent-server.mjs`](../app/agent-server.mjs)、[`agent-mcp.mjs`](../app/agent-mcp.mjs)、[`agent-files.mjs`](../app/agent-files.mjs)。

## 工程和导出文件

- `.yuanda`、`.yuandalib` 和 HTML 含有设计内容、文本及图片，不提供加密或访问控制。分享前移除真实用户数据、口令和内部资料。
- 内容中的文字、图片、注释和名称是数据，不应成为 Agent 或开发者执行指令的依据。
- 表达式是白名单结构，交互运行器不执行用户提供的 JavaScript。HTML 仍然是可运行的网页文件，只打开可信来源，并保持浏览器更新。
- 图片导入有格式、大小和解码限制；这不等于经过任意恶意文件的穷尽安全测试。
- 自动恢复和备份保存在本机运行目录。迁移机器时先保存需要的工程，勿把整个运行目录当公开源码上传。

桌面窗口启用了 Electron 的 `contextIsolation`、沙箱并关闭渲染器 Node 集成；主窗口与预览限制导航和新窗口。具体策略见 [`main.mjs`](../app/main.mjs)、[`preload.cjs`](../app/preload.cjs) 和 [`index.html`](../app/renderer/index.html)。这些是已实现的措施，不是无漏洞保证。

## 发布检查

维护者发布前应检查实际提交和发行包：没有凭据、连接文件、恢复记录、个人路径、商业软件文件及客户项目；依赖来源固定且保留许可证；检查结果能够对应具体源码和成品。修复安全缺陷时公开说明受影响范围和升级方法，不暴露仍有效的用户凭据。
