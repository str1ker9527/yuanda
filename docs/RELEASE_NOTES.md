# 发布记录

## 0.2.0-preview.9

开发预览版。目标是让桌面编辑、交互配置和本地 Agent 使用一致的能力，并为 Mac 本机开发提供入口。

- 延续 preview.8 的左上文件操作、桌面菜单、右键、网格/参考线、元件拖入外观预览及面板停靠。
- 新增事件与动作启用开关，保留各分支自己的启用状态。旧文件继续自动执行。
- 可配置“根据条件自动执行”或“显示分支菜单，让访客选择”。
- 增加右键、鼠标移动、松开按键、窗口尺寸、窗口滚动及变量变化事件；按目标类型提供可用事件。
- 交互编辑器可配置自适应视图切换、聚焦和触发其他元件事件；Agent schema 使用同一能力表。
- MCP 启动入口从应用清单读取版本号；成品检查会校验握手版本，避免更新后仍报告旧版本。
- 提供跨平台启动、依赖安装和测试路径；Mac 可在本机生成开发用 `.app`，尚未完成 Mac 真机验收、Developer ID 签名及公证。
- 公开贡献指南、安全说明、架构、完整能力清单和继续开发交接，附 Windows/macOS/Linux 的模型与接口 CI 配置。

RP 仍是有限导出：复杂交互拒绝导出，停用事件、停用动作和分支菜单不会被悄悄改为启用跳转。完整工程仍使用 `.yuanda`。

2026-10-15 在 Windows 完成本轮验证：

| 范围 | 结果 |
| --- | --- |
| 模型与本机接口 | 390 项通过 |
| 完整检查入口 | 47 组在固定应用源码下分批通过 |
| 新交互界面 / HTML 运行 | 7 / 17 项通过，包含在上述 47 组中 |
| 成品 EXE 桌面 / MCP | 19 / 13 项通过 |
| 成品与源码核对 | 893 个文件一致；运行文件与本地 Electron 相同 |

第一次完整运行在第 27 组被旧测试定位中断：新事件设置区改变了 `section` 顺序，脚本点中了禁用按钮。修正测试定位后，从该组继续完成剩余 21 组；应用源码的哈希保持一致。此结果是分批验证，不是一次全绿运行。失败记录由维护者保留，公开 [验证摘要](verification-preview.9.json) 提供检查名称、范围与源码哈希。

桌面界面检查使用真实指针/键盘；隐藏窗口的焦点检查使用 Chromium 焦点模拟。部分选择控件使用 DOM change 事件；文件对话框和剪贴板在相应检查中使用指定样本或替身。真实文件、文档引擎、本机 HTTP/MCP 和导出 HTML 均有独立运行检查。没有 Mac 真机、全套 Axure 原生兼容或远端 CI 通过结论；CI 状态以 GitHub 实际运行记录为准。

## 0.2.0-preview.8

改善文件菜单、右键、拖入预览、网格参考线及主窗口内面板停靠。Windows 本地曾完成 45 组固定应用源码下的分批检查；不是一次全部通过的整套运行。模型与接口当时为 373 项，成品桌面 19 项、成品 MCP 13 项。历史报告留在维护者本机，不是当前版的验证结果。

面板仍不是独立系统窗口；没有跨显示器浮动能力。RP 基础保存/预览/重开已有用户反馈，新图像与跳转扩展只有独立格式检查。完整范围见 [能力清单](FEATURE_MATRIX.md)。
