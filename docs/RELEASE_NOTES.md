# 发布记录

## 0.2.0-preview.11

项目参考线与拖入吸附开发预览版。新增项目级 `globalGuides` 和 schemaRevision 13 的 `setProjectGuides` 命令；普通页面和自适应视图共用项目线，母版只使用自己的线。旧工程缺少新字段时补空集合。坐标、保存、撤销与 Agent 修改进入同一文档引擎。

「视图 → 参考线」可切换本页或整个项目范围，分别添加、编辑、删除和清空。项目线显示为虚线；两种来源重合时仍分别维护。可从标尺拖出，双击精确填写，拖回标尺或按 Delete 删除；锁定和显示、吸附分别设置。Agent 更新、项目/画布切换会取消旧拖动，过期窗口拒绝覆盖新值。

基础元件、母版和本地库拖入复用整体可见边界与统一吸附：网格、本页/项目参考线、元件边缘与中点使用各自开关，预览与最终落点一致。隐藏参考线仍可参与已开启的吸附，母版画布不使用项目线。没有新增边缘自动滚动、独立系统浮动面板或 RPLIB 兼容。

HTML 不绘制这些编辑辅助线。非空项目参考线目前明确拒绝 RP 导出；原有页面目录拒绝规则继续保留，没有通用 RP 导入器。Mac 原生 GUI 尚未验收。

## 0.2.0-preview.10

页面目录开发预览版。新增独立页面文件夹，目录不再冒充空白画布。页面面板、项目菜单和右键提供入口；混合树可展开/收起、改名、拖动归类、排序及用键盘调整。Windows Ctrl / macOS Cmd 加方向键与既有 Alt 加方向键均可调整层级。

页面面板底部明确显示当前选中的页面或文件夹；父级下拉列出真实页面和目录并排除自身后代，上下移按同父级混合顺序操作。连续使用键盘选择父级时保持控件焦点。Agent 修改工程后，旧拖动和菜单取消，过期的改名或删除确认拒绝提交。

开发检查发现并修复了两处焦点问题：父级下拉提交后重绘导致连续方向键丢失；从母版切回页面后，树的延迟焦点恢复可能抢走自适应视图下拉的键盘输入。父级控件现在只在同一项目、同一选中对象内恢复焦点，树行在已有 DOM 上同步聚焦；异步命令完成时若用户已转去操作别处，不再恢复旧焦点。修复后重建了便携程序，旧运行和旧构建留存，未计作本版通过结果。

删除文件夹前显示受影响数量，可取消；确认后整组删除后代页面和目录并清理失效引用，可以整批撤销。删除普通页面仍提升其子项，不自动删除整棵子树。最后一个真实页面受到保护。

目录及顺序写入工程，Agent schemaRevision 12 提供相同命令。HTML 以树中的第一个真实页面作为首页，折叠不隐藏导出页面。目录不能成为交互跳转或画布选择目标。

含目录的 RP 导出目前明确拒绝，避免组织结构被悄悄丢弃；RP 导入和目录兼容尚未完成。旧项目缺少目录字段时按旧页面顺序读取。Mac 原生界面仍未验收。

## 0.2.0-preview.9

开发预览版。目标是让桌面编辑、交互配置和本地 Agent 使用一致的能力，并为 Mac 本机开发提供入口。

- 延续 preview.8 的左上文件操作、桌面菜单、右键、网格/参考线、元件拖入外观预览及面板停靠。
- 新增事件与动作启用开关，保留各分支自己的启用状态。旧文件继续自动执行。
- 可配置“根据条件自动执行”或“显示分支菜单，让访客选择”。
- 增加右键、鼠标移动、松开按键、窗口尺寸、窗口滚动及变量变化事件；按目标类型提供可用事件。
- 交互编辑器可配置自适应视图切换、聚焦和触发其他元件事件；Agent schema 使用同一能力表。
- MCP 启动入口从应用清单读取版本号；成品检查会校验握手版本，避免更新后仍报告旧版本。
- 提供跨平台启动、依赖安装和测试路径；Mac 可在本机生成开发用 `.app`，尚未完成 Mac 真机验收、Developer ID 签名及公证。
- 公开贡献指南、安全说明、架构、完整能力清单和继续开发交接，附 Windows/macOS/Linux 的模型与接口 CI 配置。

RP 仍是有限导出：复杂交互拒绝导出，停用事件、停用动作和分支菜单不会被悄悄改为启用跳转。完整工程仍使用 `.yuanda`。
