# 核心能力清单与已知差距

本清单按原有 162 个行为条目保留完整范围。当前源码为 0.2.0-preview.10，新增独立页面文件夹及对应 Agent 命令；本轮 Windows 检查共 48 组在固定应用源码下分两批通过，具体范围见[发布记录](RELEASE_NOTES.md)和[验证摘要](verification-preview.10.json)。preview.9 的检查保留为[历史验证摘要](verification-preview.9.json)。各行只描述明确支持的子集，不代表与 Axure 全量相同。后续变更应更新相应条目，不能把基础能力直接改记为整个能力族完成。

“基础已实现”仅指本行明说的行为；“部分”包含已实现和仍缺的子项；“缺”表示尚无完整路径；“待核”表示证据不足。Windows 已有自动检查；Mac/Linux 不继承这些验证结论。测试数量不是功能覆盖百分比。

此公开版本只保留行为和原搭状态，不分发商业软件分析材料或本机证据。实现入口见 [架构](ARCHITECTURE.md)，可重复检查入口见 [贡献指南](CONTRIBUTING.md)。公开行为参考集中列在文末；名称对应并不证明内部算法相同。
