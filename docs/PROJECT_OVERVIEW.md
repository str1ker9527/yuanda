# 原搭：项目说明

原搭（Yuanda）是一个使用 Electron 构建的桌面原型编辑器。它让人用鼠标编辑页面，也让外部 AI Agent 通过本地 MCP 工具直接修改同一份工程。两种入口共用数据校验、版本冲突检查和撤销记录。

项目目标是独立实现成熟桌面原型工具的核心工作流，并让 Agent 成为可读写的协作者。当前是开发预览版，**不是 Axure 的完整替代品，也不承诺其文件与行为全量兼容**。功能范围及剩余事项见 [完整能力清单](FEATURE_MATRIX.md) 和 [路线图](ROADMAP.md)。

## 为什么桌面程序里还有 HTML

编辑器安装或解压后在独立桌面窗口运行。Electron 用 HTML、CSS 和 JavaScript 绘制这个窗口，但原搭不需要部署一个网站才能使用。编辑器生成的 HTML 是另一种交付物：它把设计和原创交互运行器装进一个文件，供别人用浏览器体验原型。

因此，桌面编辑、可编辑工程和浏览器演示是三个相连但不同的环节。

## 可以做什么

- 绘制、排列和组合元件，编辑文字、图片、矢量路径与连接线；用页面树、概览、标签和画廊组织设计。
- 管理共享样式、本地元件库、母版实例和自适应视图；用动态面板和数据列表制作交互演示。
- 使用菜单、右键、标尺、网格、参考线、吸附和主窗口内的可停靠面板完成桌面编辑。
- 保存工程，导出独立交互 HTML，在明确支持的范围内导出原生 RP 文件。
- 连接支持 MCP 的本地 Agent，让它读取实际对象 ID，预检后直接批量修改、选择、撤销、保存或导出。

这些概括不表示每一类能力已全量实现。例如，面板可在主窗口内浮动，但尚不能变成跨显示器的独立系统窗口；母版支持文字和图片来源覆盖，但不是任意字段覆盖。

## 文件分别用来做什么

| 文件 | 用途 | 边界 |
| --- | --- | --- |
| `.yuanda` | 保存全部原搭工程数据，继续编辑、备份和迁移 | 自有 UTF-8 JSON 格式；不加密，不宜存放密钥或敏感业务资料 |
| `.yuandalib` | 交换自有本地元件库 | 不是 Axure `.rplib`，不保留库范围之外的页面跳转等关系 |
| `.html` | 独立浏览器交互演示 | 包含设计内容及内嵌资源；不是工程导入格式或业务后端 |
| `.rp` | 向 Axure 交付支持子集 | 矩形、文字、按钮、多页、静态 PNG 和单个无条件单击跳页；遇到不支持内容明确拒绝 |

**当前没有通用 RP 导入器。**不要删掉 `.yuanda` 原工程，只保留 RP 或 HTML。基础 RP 曾通过人工打开、编辑、保存、预览及重开验证；后续图片与跳页扩展完成结构检查，不能把结构检查当成全部 Axure 版本的原生验收。

## 平台与运行状态

| 平台 | 当前依据 |
| --- | --- |
| Windows | 已有便携版本、源码启动和自动桌面检查；具体发行结果以该版说明为准 |
| macOS | 是后续开发目标；需要在 Mac 上验证安装依赖、运行、打包、快捷键、权限和文件行为，不能从 Windows 通过推导为 Mac 已可交付 |
| Linux | 尚未作为已验收发行平台 |

下载源码后的开发入口是 [贡献指南](CONTRIBUTING.md)；不熟悉编程的使用者可从 [试玩指南](试玩指南.md) 开始。Agent 接入见 [Agent 接入](Agent接入.md)。

## 原创实现与项目边界

应用、示例和 HTML 运行器是独立实现。公开源码不包含 Axure 程序、反编译产物、内置素材库或私有运行脚本；Axure 名称只用于说明工作流参考与兼容目标，不表示关联、授权或官方认可。

项目采用 [MIT 许可证](../LICENSE)。Electron、MCP SDK 等第三方依赖遵循各自许可证；构建产物必须保留依赖要求的许可证和说明。项目不内置模型账户、团队云服务或商业原型资料。

公开仓库用于分发源码和协作开发。GitHub 的 Issue、代码评审或 Release 不等于原搭已经具备应用内多人协同、Axure Cloud 或项目冲突合并功能。
