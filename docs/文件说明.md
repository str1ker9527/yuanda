# 原搭的文件放在哪里，各自做什么

以下路径都相对**仓库根目录**。这份说明逐个列出应用源文件、自有开发脚本和测试的职责；不懂代码时，只需先看第一张表和 [试玩指南](试玩指南.md)。完整实现内容可直接打开对应源文件查看，无需逐个运行。

当前源码目标版本为 0.2.0-preview.10，新改动以本轮验收结果为准。应用、运行器和样本均原创编写，研究工具与 Axure 反编译材料不在应用文件清单内。

## 用户最常用的文件

便携版保留 `projects/原搭-图片与跳转演示.yuanda` 及 `exports/原搭-图片与跳转演示.rp`，本轮新增 `projects/页面目录体验.yuanda` 和 `exports/页面目录体验.html`。`Agent-MCP配置.json` 和 `Agent-Codex配置.toml` 是当前便携位置的连接示例。移动整个便携目录后，重新从应用复制接入说明。

| 文件或目录 | 内容及打开方式 |
| --- | --- |
| `dist/原搭-0.2.0-preview.10/原搭.exe` | 新版构建目标，在资源管理器双击；必须保留整个便携目录。 |

## 应用源代码

本版集成文件：`app/agent-mcp.mjs` 提供12个标准MCP工具；`scripts/yuanda-mcp.mjs` 启动协议服务；`app/agent-files.mjs` 在固定输出目录生成不覆盖旧文件的结果；`app/core/rp-export.mjs` 与 `rp-html-config.mjs` 独立编码基础RP及其保存/预览配置。`scripts/test-agent-mcp-desktop.mjs` 验证MCP到真实桌面、磁盘与HTML；`scripts/inspect-generated-rp.mjs` 是不导入写入器的独立格式检查；`scripts/generate-rp-agent-demo.mjs` 生成原创图片跳转示例。

## 自有开发与验证脚本

这些文件是开发工具，不是用户要逐个打开的程序。自动检查使用本地测试输出；通过某一类检查只说明该检查覆盖的范围。

| 文件 | 内容职责 |
| --- | --- |

## preview.10 页面目录

目录由 `app/core/page-tree-model.mjs` 和文档命令共同维护；`navigation-tools.js` 提供混合树与确认窗口，`workspace-tools.js` 的底部控件显示当前选中的页面或文件夹。选目录不会打开空白画布。父级下拉排除自身与全部后代，同级上下移同时考虑页面和目录。

示例由 `scripts/generate-page-folders-demo.mjs` 生成，工程在 `samples/yuanda/页面目录体验.yuanda`，网页在 `exports/页面目录体验.html`。便携版把工程放到 `projects/`。Agent schemaRevision 12 公开同一套目录命令；含目录的工程目前拒绝 RP 导出。操作步骤见 [试玩指南第 18 节](试玩指南.md#18-用文件夹整理页面)，验证范围见 [发布记录](RELEASE_NOTES.md)。
