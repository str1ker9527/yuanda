# 路线图与交付原则

原搭的方向是覆盖成熟桌面原型工具的核心能力，同时让外部 Agent 直接读写工程。当前预览版已经覆盖许多基础工作流，但还有大量部分实现、缺失或未验证的行为。**发布源码不代表功能目标已经完成。**

[能力清单](FEATURE_MATRIX.md) 保留 162 个行为条目及其原有编号，包括本机编辑、格式互通、外部工具、团队服务和 Agent 增强。下面的顺序是开发优先级，不删除靠后的范围，也不承诺发布日期。

## 1. 补齐高频编辑工作流

- 页面文件夹、混排、递归删除与 HTML 默认页已在 preview.10 接入（P02–P04）；继续检查大型目录与跨功能组合，并补自动画布、设备预设、浏览器对齐、页面背景与共享页面样式（P08–P12）。
- 图层过滤、深层定位、网格分布、数值间距、相对位置交换、键盘与 Tab 顺序（O01–O02、O09–O10、O13）。
- 项目全局参考线已在 preview.11 接入（H04），库拖入也接入统一吸附；仍需主窗口之外的面板与多显示器恢复、高 DPI/对比度验证、参考线显示层次/打印及视图专属继承规则（W03、W05–W07、H05–H07）。
- 空白母版入口、实例使用清单与替换、嵌套事件及更完整覆盖（C01、C03–C05、C09）。

交付需包含真实入口、数据命令、保存重开、撤销、Agent 同步，以及不会破坏未选对象的组合场景。

## 2. 完整交互、数据与专用元件

- 补齐交互目标定位、悬停/长按及尚缺的对象事件和调试能力（I01–I11）；事件/动作开关和分支选择菜单已在 preview.9 接入，仍需检查更多组合。
- 外链与窗口/框架目标、运行时换图、旋转/层次、组件抛出事件、动作动画、局部变量和函数库（A01–A13）；已有聚焦和同画布事件转发不等于整类动作完成。
- 面板多状态编辑、状态外观、宽度适配、循环与手势；重复器图片/页面列、命名筛选和更多布局（D01–D09、R01–R08）。
- 列表框、树、快照、内联框架、热区和菜单；普通表格的单元格属性、二维粘贴和尺寸编辑（F01–F13）。

运行器行为必须通过导出 HTML 验证。新增一个事件名称并不等于输入触发、队列、目标作用域和删除/切页取消行为都已实现。

## 3. 绘制、资源与文档交付

- 流程图、形状转换、布尔几何、可编辑 SVG、复杂连接线路由/标签与外框旋转后的独立文字（P07、G01–G14）。
- 图像资源去重、系统剪贴板与更多图像编辑组合；各类复杂状态样式、字体与跨设备呈现验证（G07–G10、S01–S10）。
- 本地图像目录、库更新和更完整的冲突策略；多字段富文本注释、编号、引用、HTML 文档面板、规格说明与打印（L03–L08、N01–N07）。

界面、保存格式与输出内容要对应，不用静态截图冒充可更新的快照引用，也不用按钮外观冒充缺失算法。

## 4. 文件互通与项目可靠性

- 扩展 RP 支持子集，包括目前明确拒绝的页面文件夹组织和项目全局参考线，建立按 Axure 版本划分的原生打开/编辑/保存/重开样本；实现导入和往返之前继续保留完整 `.yuanda` 工程（X03）。
- 独立实现并验证 RPLIB 互通与 Figma/Sketch/XD 等插件入口（L05、G14）。
- 项目导入合并、故障注入、恢复与备份 UI、复杂内容的预览一致性和播放器调试能力（X01–X07）。

格式兼容通过语义与实际应用行为验证，不以扩展名、可解压或字段名称相似为完成依据。不支持的数据明确拒绝，不能静默丢失。

## 5. 平台、Agent 与协作

- 在 Mac 真机完成依赖安装、启动、打包、菜单/快捷键、文件权限与 Agent 联调；发布苹果版本前另行处理签名、公证与分发。Windows 通过不能替代 Mac 通过。
- 完善 Agent 的逐字段变更预览、命令全链验证和复杂母版/视图操作；保留版本冲突和整批撤销语义（AI01–AI06）。
- 内置自然语言模型连接是独立功能域。当前可由外部 Agent 通过 MCP 直接控制，不要求使用者手工粘贴 JSON（AI07）。
- 团队库同步、签出/提交、历史、冲突和云端评审需要独立服务、账号权限和联机验收，仍属长期范围；GitHub 项目发布不能替代这些能力（L08、X08）。

## 什么才算完成

每项交付写清支持范围与剩余范围，检查模型、真实 UI、文件往返、Agent 和 HTML 中相关的路径，再核对发行包。模型测试数量、菜单数量或源码存在都不能单独支持“完全覆盖 Axure”的结论。

发现旧条目与新源码不一致时，依据实际实现和检查结果修正条目，并保留未验证的边界。可在 Issue 中引用能力编号，使讨论和 PR 能对应同一项行为。
